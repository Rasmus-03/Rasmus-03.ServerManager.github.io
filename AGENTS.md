# Project instructions

## Commits carry no AI attribution

Never put attribution to an AI tool in a commit message: no `Co-Authored-By:`
trailer naming an assistant, no `Generated with ...` or `🤖 Generated with ...`
footer, and no mention of an assistant, agent or model anywhere in the message.

Write every message as the project author: a subject that says why the change was
made, an optional body explaining the problem, and nothing after it.

The history of this repository has been rewritten to remove such lines, so they
must not come back. If a tool or template adds them anyway, strip them before
committing or pushing.
